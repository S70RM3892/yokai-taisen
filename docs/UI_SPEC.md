# UI 仕様書 v0.2（バトル画面）

> 方針：**操作と画面の配置は本家（YW2）と同じ。見た目はすべてオリジナル。**
> P2（ブラウザで人 vs CPU）の画面はこれに沿って作る。絵がまだないので、P2 は四角・丸・文字で組む。

---

## 0. 著作権の線引き

| まねしてよい（アイデア） | まねしない（表現） |
|---|---|
| 上が戦闘・下がホイールという2画面の構成 | ウォッチ（腕時計）のデザイン、見た目 |
| ホイールを回して前衛と後衛を入れ替える操作 | アイコン・ボタンの絵柄、フォント、配色の組み合わせ |
| ホイールの周りにボタンを置く配置 | キャラ・エフェクト・効果音・ボイス |
| 奥義のときに下画面でスキルチェックをする流れ | 「わざ」「ねらう」「おはらい」などの原作の言葉 |

- UI の配置や操作は、著作権では「アイデア」扱いで守られにくい（釣りゲーム訴訟では、画面の配置や画面の移り方の類似について侵害が認められなかった）。
- 一方で、画面の具体的なデザインは美術の著作物になりうる。また、2020 年の意匠法の改正で、画面のデザイン（GUI）も意匠登録できるようになった。
- **公開前に、専門家に一度確認してもらう。**

## 1. 画面の構成

本家は 3DS の2画面（上：戦闘の様子、下：タッチでホイールを操作）だった。ブラウザでは **上下に2画面を並べる**。

### 1.1 スマホ（縦持ち）― 基本の形
```
┌──────────────────────┐
│      上画面：戦闘       │  約 55%
│  敵の前衛3体（奥）      │
│  味方の前衛3体（手前）   │
├──────────────────────┤
│      下画面：操作       │  約 45%
│  [奥義]       [標的]   │
│       ╭─ホイール─╮      │
│       │  [ゼロ]  │      │
│       ╰─────────╯      │
│  [浄化]                │
└──────────────────────┘
```
縦持ちのスマホは、3DS の上下2画面にそのまま当てはまる。

### 1.2 PC（横長）
- 上下2画面を **画面の中央に縦に並べる**。縦横比は固定して、左右の余白に対戦ログを出す。
- マウスで下画面をクリック・ドラッグして操作する。キーボードでも操作できる（§4）。

### 1.3 上下の比率
- 本家の画面サイズは、上 400×240・下 320×240（3DS）。本作は比率だけ参考にして、上を少し大きくする。

## 2. 上画面（戦闘）

本家は「妖怪たちの動きと必殺技のアニメーション」だけを見せていた。本作はこれに、**本家では見えなかった情報を足す**（`PLAN.md` §1.3：情報が見えないのが本家の弱点だった）。

| 表示 | 位置 | 本家との違い |
|---|---|---|
| 両チームの前衛3体 | 敵が奥、味方が手前 | 同じ |
| 後衛の SG | 上画面の端に、後衛3体の SG を小さく出す（相手の分も） | 大奥義の電池になるので見せる |
| HP バー | 各ユニットの下 | 同じ |
| **行動ゲージ（AG）** | HP バーの下に細く | **本家は隠し値だった → 見せる** |
| なまけ中 | ユニットの頭の上にアイコン。つつける敵は光らせる | 原作どおり（予告はしない。`BATTLE_SPEC.md` §4.2） |
| クリティカル | ダメージの数字を大きく出す | 同じ |
| 呪付・加護 | ユニットの横にアイコン＋残り時間 | 残り時間を見せる |
| **相手の構え** | 構えているユニットが光る。大奥義はさらに目立つ演出 | **相手に見せる**（読み合いの材料） |
| 標的 | 狙っている敵に照準マーク | 同じ |
| 陣 | 画面の端に、発動している陣の名前 | 同じ考え方 |
| 残り時間 | 画面の上の中央 | 追加 |

- 本家の「ねらう」は、上画面のレンズで照準を合わせる操作だった。本作は **上画面の敵を直接タップ** しても標的にできる（§3.3）。

## 3. 下画面（操作）

### 3.1 ホイール
- 6体を円に並べる。**上半分の3つが前衛、下半分の3つが後衛**（`BATTLE_SPEC.md` §12.1 の位置 0〜5 と対応）。
- 各ユニットの顔（P2 では名前の頭文字）に、HP・SG のリングと、呪付のマークを重ねる。
- **回す**：ホイールを指でなぞって回す（本家と同じ）。1回で1つ分。回したあとの待ち時間（3 秒。原作の3秒ルール）は、ホイールの外側のリングで見せる。
- 戦闘不能のユニットは暗くして、ホイールに残す。

### 3.2 ホイールの周りのボタンと「ゼロ」
本家（零式）と同じく、**ホイールの中央に「ゼロ」ボタンを置く**。ゼロを押すと、上の2つのボタンが切り替わる。

| 位置 | ふだん | ゼロを押したとき | 本家での相当 |
|---|---|---|---|
| 左上 | **奥義** | **大奥義** | 必殺技 ↔ G技 |
| 右上 | **標的** | **つつき** | ねらう ↔ つつく |
| 左下 | **浄化** | **浄化**（変わらない） | おはらい |
| 右下 | （空き） | （空き） | 本家ではアイテム。本作は戦闘中のアイテムがないので空ける |

- **奥義**：前衛で SG が満タンのユニットが光る → タップで構え（§3.4）。
- **大奥義**：撃てるユニット（自分と、ホイールの両隣の SG が満タン）がいるときだけ押せる。撃てるユニットと、使う両隣がホイール上で光る → 構えるユニットをタップ（`BATTLE_SPEC.md` §6.5）。
- **標的**：上画面の敵をタップして選ぶ（§3.3）。
- **つつき**：上画面で、呪付のかかった敵・なまけている敵が光る → タップでつつき開始（§3.6）。つつける敵がいないとき・構えているあいだは押せない（`BATTLE_SPEC.md` §8.4）。
- **ゼロの状態は画面だけのもの**。戦闘の中身（`BATTLE_SPEC.md`）には関係しない。押してもゲームは止まらず、待ち時間もない。
- ゼロ状態のときは、ホイールとボタンの色を変えて、今どちらの状態かひと目でわかるようにする。
- 大奥義を撃ったあと・つつきが終わったあとは、自動でふだんの状態に戻す（案）。
- 右下の空きは、あとで何か置くかもしれない（§6）。

### 3.3 標的
- 「標的」ボタン → 上画面の敵をタップ、または **上画面の敵を直接タップ**。どちらでもよい。
- 切り替えの待ち時間（1 秒）中は、照準マークを薄くする。

### 3.4 奥義のスキルチェック（下画面）
本家は、必殺技のときに下画面が切り替わり、「回す」「なぞる」「飛んでくる玉をタッチ」などのミニゲームをクリアすると発動した。本作は **下画面を切り替えるところまで同じ** にして、中身は `BATTLE_SPEC.md` §6.2 の「溜め＋タイミング判定」にする。

```
┌──────────────────────┐
│  溜め：■■■□  1.1倍   │
│        ╭───╮          │
│      ╱  ▲  ╲  ← Perfect の位置
│     │   ●   │  ← 回るカーソル
│      ╲     ╱          │
│        ╰───╯          │
│  [キャンセル]   [解放]  │
└──────────────────────┘
```
- リングの上を、カーソルが 0.8 秒で1周する。Perfect と Good の範囲に色を付ける。
- 「解放」ボタン、またはリングのタップで解放する。
- 溜めの段階（1.0 → 1.1 → 1.2 倍）を上に表示する。2 秒を超えると自動で解放されるので、残り時間も見せる。
- **構えている間も、ホイールは小さくして画面の端に残し、回せるようにする**（構えたユニット自身を後ろに回すとキャンセルになる）。
- 大奥義のときは、リングの見た目を変えて、使う3体（両隣の後衛も含む）の顔を周りに並べる。
- 大奥義の構え中は、ホイールを回すとキャンセルになることを画面で警告する。

### 3.5 浄化の表示
- 浄化中のユニットには、ホイール上で 2 秒の進みぐあいをリングで見せる。

### 3.6 つつき（下画面）
本家と同じく、**つつき中は下画面が対象の敵の顔に切り替わる**。中身は `BATTLE_SPEC.md` §8.4。
```
┌──────────────────────┐
│ 残り 2.1秒  ゲージ ■■■□□ │
│ ┌──┬──┬──┬──┐          │
│ │  │  │★ │  │ ← 弱点（0.5秒ごとに動く）
│ ├──┼──┼──┼──┤          │
│ │  │ 敵の顔 │  │          │
│ ├──┼──┼──┼──┤          │
│ │  │  │  │  │          │
│ └──┴──┴──┴──┘          │
│            [やめる]     │
└──────────────────────┘
```
- 4×4 のマスは見た目では線を出さず、顔の上に弱点のマークだけを出す（当たり判定はマス単位）。
- 弱点に当たったら大きめのエフェクト、それ以外は小さいエフェクト。
- つつき中はホイールを出さない（回せないため）。代わりに、上画面の様子は上画面でそのまま見える。
- つつかれている側の画面では、自分のユニットに「つつかれている」表示とゲージを出す。

## 4. 入力の対応表

| 操作 | タッチ | マウス | キーボード（案） |
|---|---|---|---|
| 時計回りに回す | ホイールをなぞる | ドラッグ | E |
| 反時計回りに回す | ホイールをなぞる | ドラッグ | Q |
| 奥義 | ボタン → ユニット | クリック | 1・2・3（前衛の位置） |
| 大奥義 | ゼロ → 大奥義 → ユニット | クリック | Z → 1・2・3 |
| 解放 | 解放ボタン／リング | クリック | Space |
| キャンセル | キャンセルボタン | クリック | Esc |
| 標的 | 敵をタップ | クリック | Tab で切り替え |
| 浄化 | ボタン → ユニット | クリック | 4・5・6（後衛の位置） |
| ゼロの切り替え | 中央のゼロ | クリック | Z |
| つつき開始 | ゼロ → つつき → 敵 | クリック | Z → Tab で敵を選んで Enter |
| つつく | 下画面をタップ | クリック | （マウス・タッチのみ） |
| つつきをやめる | やめるボタン | クリック | Esc |

- ボタンが押されたら、`BATTLE_SPEC.md` §11 の入力に変換する。
- **タイミング判定は、ボタンが押された瞬間の tick で決める**。オンラインでは、入力に tick 番号を付けて送る（遅延の対策は P3 で決める）。

## 5. 編成画面（あとで詳しく決める）
- 6体の並び（ホイールの最初の配置）、性格、努力ポイント、装備を決める。
- 対戦前に、相手のユニットと性格だけが見える（努力ポイントと装備は見えない）。

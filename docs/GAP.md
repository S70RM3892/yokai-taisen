# 本家（妖怪ウォッチ2）との差と、埋めたところ

このゲームの対戦画面は、本家の対戦（下画面のメンバーサークルと四隅のボタン、零式の Gわざ・つつく）をまねて作られている。
2026-09 に本家の仕様を攻略サイトで確かめ、足りなかったところを埋めた。

## 比べた結果

### このゲームへの合わせ方
- 本家の種族は、陣の効果が同じこのゲームの族に入れた（イサマシ→猛・フシギ→怪・ゴーケツ→剛・プリチー→影（すばやさ）・ポカポカ→和（回復）・ウスラカゲ→雅（能力を下げるとりつき）・ブキミー→祟（状態のとりつき）・ニョロロン→鎮（とりつかれにくさ）・怪魔→禍）。
- 本家の妖怪のとりつきは、敵向き（悪い）か味方向き（よい）のどちらか一方だけ（本家と同じ）。
- 全体攻撃の必殺技は本家では「○ x ○回」を敵に散らして当てるので、1 体あたりの威力は合計の 0.55 倍にした。
- 妖怪は攻略大百科「妖怪大辞典」のページ（monsters/138〜535 の 398 体。それより前後の番号は妖怪のページではない）と 1 体ずつ見比べた（2026-09-26 に取り直して差なし）。ここにいない妖怪はいない。
- こうげきの威力・弱点は HRS から取る。HRS で名前の書き方がちがう 7 体（とどろき獅子 (轟獅子)・ズルズルつる・TETSUYA (てつや)・KANTSUYA (かんてつ)・かりパックリ・カブニャン・青龍(青竜)）も同じ妖怪としてつないだ（以前は推定の威力だった）。HRS にない怪魔 15 体だけは攻略大百科のいりょくからの推定。
- 弱点は HRS に書かれている妖怪（398 体中 57 体）はその値。書かれていない妖怪は「ようじゅつの属性に強い属性」を弱点・ようじゅつの属性を耐性にした（推定）。
- お金・経験値・アイテムが落ちやすくなる・仲間になりやすくなるスキルと魂は、対戦では効果なし（説明にそう書いた）。
- 「深夜テンション」（夜の間）は、対戦の後半（3 分すぎ）に全能力アップにした。「リーゼント」（ずつき系のわざを受けない）は、わざの種類がないので こうげきのダメージ -20% にした。
- 3D モデルは 1 体ずつ手で作る代わりに、名前の言葉（ニャン・鬼・天狗・カッパ・蛇・鳥・姫・爺…）と種族から体つきを選んでいる。

本家の数字が見つからないので このゲームで決めたもの：サドンデスの始まる時間（5 分）と時間切れ（6 分・残り HP の割合）、
つつくの一撃の出る割合（0%：このゲームでは出さない）と HPダメージの量（最大 HP の 20%）、よいとりつきの続く長さ（3〜5 行動。英語 Wiki は「5 ターン以上」）、回復の乱数（±2%）。

### 対人戦の通信

| 項目 | 以前 | 今回 |
|---|---|---|
| 入力の遅れ | ホストの入力はすぐ効き、ゲストの入力は片道の通信時間ぶん遅れて効く（回転・ひっさつわざの取り合いでホストが有利） | ホストの入力も、ゲストの片道の通信時間（往復の半分、上限 0.4 秒）だけ遅らせて効かせ、両者をそろえる（遅延方式の考え方） |
| タブが裏に回ったとき | 描画が止まると対戦も止まる（ホストがアプリを切りかえると相手も止まる） | Web Worker のタイマーで進め続ける |
| 通信の往復 | 表示なし | 対戦の最初にログへ出す |
| 版のちがう相手 | 計算が変わっても同じ版あつかい | 対戦の計算が変わったので版を 4 にした（古い版の人とは当たらない） |

これからの案（まだ入れていない）：
- **TURN サーバー**：会社・学校・一部のモバイル回線では直接つながらない。TURN（中継）を入れればつながる。Open Relay（Metered）は無料で月 20GB だが、登録して API キーを取る必要がある。
- **切れたときのつなぎ直し**：いまは 8 秒で「中断」。同じ部屋に 30 秒以内なら戻れるようにできる（ホストが状態を持っているので、戻ってきたゲストに全体の状態を送り直せばよい）。
- **ロールバック方式**：対戦は整数計算で同じ入力なら同じ結果になるので、ゲスト側で先に進めて、ホストの結果が来たら巻き戻す方式にもできる。
  ただし攻撃のモーションやダメージの数字を巻き戻すのが難しい。この対戦は反射神経のゲームではないので、いまの遅延方式で十分とみた。

## 数値のきめ方

- 性格の行動の割合（こうげき 80% など）は本家では公表されていないので、「重視」「特化」の強さに合わせてこのゲームで決めた。やさしい・情け深いの「回復」は、味方へのとりつきとようじゅつの割合を上げて表した。
- 性格の前半（まじめさ）のサボりやすさの倍率（超まじめ 0.25 倍〜超ずぼら 3 倍）も本家では公表されていないので、このゲームで決めた。本家の 7 つめの「ビビり」は入れていない。

- 本家の「ちから / ようりょく / まもり / すばやさ」はこのゲームの ATK / SPA / DEF / SPD と同じ尺度として、装備の数値をそのまま足す。
- 攻略サイトで数値が食い違う装備は Yo-kai Watch Wiki の値を使った（ゲームエイトの一覧はコメント欄で鬼神・伝説のうでわの誤りが指摘されている）。
- まず～い漢方の回復量は「HP1」（HRS）と「1/4」（Yo-kai Watch Wiki）で食い違う。1 だと使い道がないので 1/4 にした。
- おふだは本家では「一時的に上げる」としか書かれていないので、このゲームでは 15 秒のあいだ +30%（味方へのよいとりつき「ちから・ようりょくアップ」と同じ強さ）。
- 妖気ゲージは満タン 1000 として、牛乳・ジュースの回復量をそのまま使う。

# 本家（妖怪ウォッチ2）との差と、埋めたところ

このゲームの対戦画面は、本家の対戦（下画面のホイールと四隅のボタン、零式の G わざ・つつく）をまねて作られている。
2026-09 に本家の仕様を攻略サイトで確かめ、足りなかったところを埋めた。

## 比べた結果

| 本家の要素 | 以前のこのゲーム | 今回 |
|---|---|---|
| 下画面の四隅：ひっさつわざ・ねらう・おはらい・**アイテム** | 右下が空き（押せない） | 右下を「アイテム」にした。持ち物を選んで、ホイールの妖怪に使う（気絶した妖怪には漢方） |
| パワーチャージは 4 種（まわせ！／なぞれ！／打て！／あわせろ！）からランダム | タイミングで押す 1 種だけ | 4 種を入れた。本家と同じく最後まで終えると発動（ためや出来で威力は変わらない。時間切れの自動発動もない） |
| おはらいのタッチアクションは 5 種（つぶせ／連打／こすれ／まわせ／斬れ） | 後衛に下げると 2 秒で自動 | 5 種を入れた。何もしなくても 10 秒ではらえる（CPU は難しさに合わせて速く） |
| 装備（うでわ・ゆびわ・おまもり・バッジ・専用・呪言・はちまき・勲章など） | このゲーム独自の 9 種。選ぶ画面がない（CPU だけ持つ） | 本家の 74 種をすべて追加。専用装備は近い一族に割り当て。独自 9 種（剛力の腕輪・形代など）は本家にないので消した |
| 魂（魂へんげ）を装備 | なし | 396 体すべての魂。その妖怪の特性を半分の強さで持てる |
| 妖怪ごとのスキル | 31 種をみんなで使い回し | 396 体すべてに固有の特性（名前も中身も全員ちがう。テストで確認） |
| たべもの（HP 回復）・好物 1.25 倍 | なし | 本家のたべもの 66 種。好物なら 1.25 倍 |
| 牛乳・ジュース（妖気） | なし | 8 種 |
| おふだ・漢方・みがわり人形 | なし | ちから／ようりょく／まもり／すばやさのおふだ、まず～い・にが～い・ふか～い漢方、みがわり人形（逃げる） |
| 性格（前半＝まじめさ・後半＝行動の傾向） | 独自の 8 種（猛攻・術重など）。前半はない | 本家の 12 種（短気・荒くれ・れいせい・ずのう的・やさしい・情け深い・いやらしい・非道・協力的・けんしん的・しんちょう・動じない）と、前半の 6 段階（超まじめ〜超ずぼら）。前の版の性格は近い本家の性格として読む |
| 能力の伸ばし方 | 独自の「育成」（力・速などのプリセット） | 本家にはないので消した。本家と同じく性格ボーナス（対戦のたびに伸び、合計 20 まで）を伸びきった値で入れる（荒くれ＝ちから+20、短気＝ちから+7・HP+13 など） |
| 選ぶ画面 | 性格・持ち物はプルダウン、アイテムは種類ごとの一覧 | どれも「しぼりこみ」と「ならべかえ」つきの画面。性格は行動の割合・ボーナスで、持ち物はその妖怪に付けたときの能力の上がり方で、アイテムは効き目（チームの好物なら 1.25 倍で比べる）で並べられる |
| 元祖軍・本家軍 | なし | 全員に割り当て（元祖はちまき・本家はちまきの効果に使う） |
| 対戦の妖怪は 3D | 2D の絵を板に貼って表示 | 全員に 3D モデル（一族ごとの体つき＋ 1 体ずつの色・大きさ・飾り） |
| 零式：G わざ・つつく／ねらう／ホイール回転／種族の陣形 | あり | そのまま |
| 対戦は通信対戦（人 vs 人） | 人 vs CPU だけ | 対人戦を追加（WebRTC・同じブラウザの 2 画面）。対人戦ではアイテムはなし、持ち物（装備）は効く |
| アイコンと 3D の姿が同じ | アイコンは役割ごとの共通の絵に色を付けただけで、3D モデルと別物 | 3D モデルをその場で撮ってアイコンにした（全員） |

## 入れなかったもの

対戦に関係しないアイテムは入れていない：けいけんちだま（レベルがない）、こけし（お金がない）、性格を変える本（編成画面で性格を直接選べる）、
虫・魚、合成の素材、大事な物、ガシャのコイン。敵に食べ物をあげて友達にする仕組みも、対人戦なので入れていない。

## 数値のきめ方

- 性格の行動の割合（こうげき 80% など）は本家では公表されていないので、「重視」「特化」の強さに合わせてこのゲームで決めた。やさしい・情け深いの「回復」は、味方へのとりつきとようじゅつの割合を上げて表した。
- 性格の前半（まじめさ）のサボりやすさの倍率（超まじめ 0.25 倍〜超ずぼら 3 倍）も本家では公表されていないので、このゲームで決めた。本家の 7 つめの「ビビり」は入れていない。

- 本家の「ちから / ようりょく / まもり / すばやさ」はこのゲームの ATK / SPA / DEF / SPD と同じ尺度として、装備の数値をそのまま足す。
- 攻略サイトで数値が食い違う装備は Yo-kai Watch Wiki の値を使った（ゲームエイトの一覧はコメント欄で鬼神・伝説のうでわの誤りが指摘されている）。
- まず～い漢方の回復量は「HP1」（HRS）と「1/4」（Yo-kai Watch Wiki）で食い違う。1 だと使い道がないので 1/4 にした。
- おふだは本家では「一時的に上げる」としか書かれていないので、このゲームでは 15 秒のあいだ +30%（味方へのよいとりつき「鼓舞」と同じ強さ）。
- 妖気ゲージは満タン 1000 として、牛乳・ジュースの回復量をそのまま使う。
- 専用装備の持ち主は本家の妖怪がこのゲームにいないので、いちばん近い一族にした（例：ベル → 猫の一族、天狗のうちわ → 天狗の一族、ロボビタミンE → 器物の一族）。

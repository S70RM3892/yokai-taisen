# 本家と比べた改善点と、足したほうがいいもの（2026-09-26）

v1.8.0 の時点で、本家（妖怪ウォッチ2 元祖/本家/真打）の対戦画面・妖怪 398 体・装備・魂・性格・タッチアクションはほぼ埋まっている（[GAP.md](GAP.md)）。
ここでは **まだ本家とずれているところ** と、**本家にはないけれど足したほうがいいもの** を、効果の大きい順に並べる。

## B. 本家にはないが、足したほうがいいもの

### B1. リプレイ（保存・再生・共有）— いちばん効果が大きい

対戦ロジックは「同じ入力なら必ず同じ結果」になり、対人戦もそれを使って 1 tick ごとの入力だけを送っている（README「しくみ」）。
なので **乱数の種＋両チーム＋ tick ごとの入力** を残せば、動画なしで対戦をまるごと再生できる。

- 決着画面に「リプレイを保存」。最近の 20 戦は自動で `localStorage` に残す
- 再生は 1/2/4 倍速・一時停止・どちら側から見るか
- `YT1:` と同じように `YR1:` の文字列で書き出し／読みこみ（強い人の立ち回りを共有できる）
- 入力は変化のあった tick だけを残せば、6 分の対戦でも数 KB で収まる見込み
- 版がちがうと結果がずれるので、版を入れておいて、ちがう版では「再生できない」と出す

### B2. CPU の相手を選べる（流行りの型と戦う練習）

今の CPU のチームは完全にくじ（`s0`：ランダムな妖怪・性格・装備）。流行りの型に勝つ練習ができない。

- 相手を「くじ」「流行りの型（6 つから選ぶ／くじ）」「マイセット」から選ぶ
- 自分のマイセットどうしを CPU どうしで戦わせる「CPU 観戦」（`npm test` の CPU 対戦と同じ仕組み）で、型の相性を見られる

### B3. 対戦のあとのくわしい振り返り

今の決着画面は MVP（与ダメージ最大）と、会心・弱点・撃破・奥義の回数だけ（`e.stats`）。

- 妖怪ごとの与ダメージ・受けたダメージ・回復量・サボった回数・とりつきの成功率の表
- 時間ごとの両チームの HP 合計のグラフ（どこで流れが変わったか）
- B1 のリプレイの、その場面へ飛べるようにする

### B4. 編成の診断

- 6 体の弱点・耐性を属性ごとに数えて、同じ弱点が 3 体以上なら知らせる
- 前衛 3 体の種族の陣がそろうかを、編成画面で先に出す（今は対戦中のカットインでだけ分かる）
- 流行りの型 6 つとの相性（こちらの術の属性が相手の弱点をつける数など）を目安で出す

### B5. 対人戦を続けやすく

- 今は接続が切れるとその対戦は「中断」で終わる（`pvp.js`）。**切れても 30 秒は待って、つなぎ直したら 5 秒ごとの状態合わせから再開**する
- 対人戦だけの戦績に、かんたんなレート（Elo。自分の端末だけ）を出す
- 同じ相手との「もう一戦」で、編成を変えてからつなぐ

### B6. 遊びやすさ

- はじめての人向けの **操作の手引き**（ホイール・ねらう・おはらい・アイテム・パワーチャージを CPU の「やさしい」相手で 1 つずつ）
- 演出の **倍速／奥義のカットイン省略**（今は光の粒を減らす `reduced` だけ）

## やる順番の案

1. A1（ルール選択）・A4（時間切れを書く）… 小さく、本家に近づく
2. B2（CPU の相手を選ぶ）… 流行りの型の練習がすぐできる
3. B1（リプレイ）→ B3（振り返り）… いちばん効くが中くらいの手間。B3 は B1 の上に作る
4. A2（陣営）・B5（再接続・レート）… 対人戦の人が増えてから
5. A3・B4・B6

# 流行りの型（プリセット）と本家の編成

編成画面の「流行りの型」は、本家（妖怪ウォッチ2）の通信対戦で流行った編成をそのまま入れるプリセット。
以前は本家の名前を画面に出さない決まりがあったが、プレイヤーの決定（2026-09-26）で外し、編成に出てくる妖怪は本家の名前・本家に寄せた見た目にした。

## 中身

2026-09-26 から、編成に出てくる妖怪は **中身もすべて本家** のデータ（Lv60 の能力値・ランク・種族・こうげき・ようじゅつ・とりつき・必殺技・スキル・魂）。
データは本家の妖怪 372 体と同じ出典（攻略大百科「妖怪大辞典」・HRS「全妖怪データ一覧」・ゲームエイト「魂一覧」）で、`tools/gen_honke.py` がほかの本家の妖怪と同じく書き出す。
以前は本家の数値がこのゲームになかったので、役割の近いこのゲームの妖怪（面霊気 → ブリー隊長など）の能力を借りていた。いまはこのゲーム独自の妖怪そのものを消したので、3D モデルの形だけがそのときのもの（`HONKE_NAME_MODEL`）。

このゲームで効果を足した本家のスキル：エクササイズ（となりのちから+10%）・ベンチウォーマー／美脚（後衛から前衛を回復）・みらいよち（よける）・超ガマン（2 回 HP1 でこらえる）・猛虎のねばり（1 回）・なめらかオイル・肉食オーラ／草食オーラ（前衛にいる間、敵味方全員がこうげきを選びやすく／にくくなる）・ひとまかせ・トリプルヘッド（ようじゅつが敵全体に当たる）・わしのもの（よいとりつきを全部自分に）・満を持す（2 回に 1 回しか行動しない）。

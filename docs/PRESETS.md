# 流行りの型（プリセット）と本家の編成の対応

編成画面の「流行りの型」は、本家（妖怪ウォッチ2）の通信対戦で流行った編成の **型**（役割と並び）を、このゲームの妖怪で組み直したもの。
CLAUDE.md の IP の決まりに従い、本家の妖怪の名前はこの分析の中だけで使い、ゲームの画面・コードには出さない。

## 足した妖怪（役割がこのゲームになかった分）

| このゲーム | 本家で当たる役割 | 新しい特性 |
|---|---|---|
| 久米仙人（怪・C） | ひとまか仙人：「攻撃ターンを両隣のアタッカーに割り振る」（攻略大百科） | 順送り：行動すると、となりの前衛の味方の番が 25〜35% 早く来る |
| 油坊（怪・D） | あせっか鬼：「なめらかオイル」でサークル回転を補助（攻略大百科） | 油差し：チームにいると、ホイールを回したあとの待ち時間が 25〜45% 短くなる（いちばん強いもの 1 つ） |

ほかの役割（全能力アップ・挑発・会心・ガード破り・先駆け・かばう・二度の踏ん張り・照り返し・吸い取り・妖気うばい・回復の後衛・呪言の刀）は、すでにいる妖怪の特性・とりつき・持ち物で組めたので足していない。
魂の指定（イザナミの魂など）は、このゲームの魂が「その妖怪の特性の半分」なので対応させず、持ち物（装備）だけ本家の編成に近いものを付けた。

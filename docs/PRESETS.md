# 流行りの型（プリセット）と本家の編成

編成画面の「流行りの型」は、本家（妖怪ウォッチ2）の通信対戦で流行った編成をそのまま入れるプリセット。
以前は本家の名前を画面に出さない決まりがあったが、プレイヤーの決定（2026-09-26）で外し、編成に出てくる妖怪は本家の名前・本家に寄せた見た目にした。

## 出典（2026-09 に確認）

- HRS「妖怪ウォッチ2 通信対戦(公式ルール)の攻略｜おすすめチーム編成 Ver.2.0」 <http://hrs-game.main.jp/youkai_watch2/data/article_03-3.html>
- 攻略大百科「【妖怪ウォッチ2】おすすめ最強パーティー｜タイプ別のおすすめチーム」 <https://gamepedia.jp/youkai-yw2/archives/5189>
- 攻略大百科「妖怪一覧」（さきがけの助：イサマシ B、万尾獅子：イサマシ A） <https://gamepedia.jp/youkai-yw2/monsters>

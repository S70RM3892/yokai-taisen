# 妖怪大戦

ブラウザで遊ぶ、妖怪 6 体どうしのリアルタイム対戦（人 vs CPU・人 vs 人）。1 ファイルの HTML で動く。
本家（妖怪ウォッチ2）の対戦画面の配置をまねている。**妖怪・装備・アイテムは本家にあるものだけ**。本家との差と埋めたところは [docs/GAP.md](docs/GAP.md)。

- **本家（妖怪ウォッチ2 元祖/本家/真打）の妖怪 398 体**（ジバニャン・コマさん・キュウビ・ブシニャン・赤鬼・青鬼・黒鬼・怪魔など）。能力値（Lv60）・ランク・種族・こうげき（段数）・ようじゅつ・とりつき・必殺技・**スキル**・好物は本家どおり。このゲーム独自の妖怪はいない
- 全員に **3D モデル**（アイコンも同じ 3D モデルをその場で撮った絵）
- 本家の **魂** を全部：398 体それぞれの「○○の魂」と、**レア魂 27 種**（ちょうはつ魂・おんみつ魂・ガード魂・閃光魂・なめらかオイル魂・れんごく魂など）を持ち物として選べる
- **パーティの保存**：いま組んでいる編成はいつも保存（開きなおしても続きから）。**マイセット 8 つ**（名前をつけられる）。**書き出し／読みこみ**（`YT1:` で始まる文字列で別の端末へ）。妖怪は本家の図鑑 No と名前、持ち物は id と名前で保存するので、**アップデートしても編成がくずれない**（読めないものだけを外して知らせる。前の版の保存も読める）
- **本家のような行動のモーション**：こうげきはわざの名前どおりの 17 種（パンチ・連打・はたく・ひっかく・かみつく・しっぽ・けり・ずつき・体当たり・のしかかり・ふりおろし・ふりまわし・突き・斬る・ロケットパンチ・飛び道具など）。ようじゅつは足もとに属性の字の **術の陣** を出し、相手に **火柱・水・稲妻・岩/いん石・氷のとげ・竜巻・吸収・回復の光**（術の強さ 3 段階で大きさが変わる）。とりつくは半透明で相手の上へ飛ぶ。ガードは腕を組んで **六角の結界**。サボりは寝る・あくび・よそ見・おどる。被弾でのけぞり、よけると残像、気絶は吹っとんで **魂が抜ける**。メンバーサークルで前に出ると跳んで着地、決着後は勝ち負けのポーズ。行動できない（★）・混乱（？）・サボり中（Z）のしるし
- **とりつき**は本家どおり：悪いとりつき中はひっさつわざを使えない（パワーチャージ中にとりつかれると解ける）・おはらいするまで消えない。よいとりつきはターン（その妖怪の行動）で消える。とりつかれている妖怪にはずっとオーラ（よい＝金の光、悪い＝紫の煙）
- メンバーサークルを回して **陣形効果**（同じ種族が 2 体以上ならぶ）ができたら、種族と効果をカットインで出す
- 画面の言葉は本家のまま：ひっさつわざ（ボタンは「わざ」）・Gわざ・ねらう・おはらい・とりつき・零式・つつく・メンバーサークル・スキル・そうび。種族はイサマシ・フシギ・ゴーケツ・プリチー・ポカポカ・ウスラカゲ・ブキミー・ニョロロン・怪魔
- ひっさつわざの「敵全体に攻撃」は前衛の敵それぞれにそのままの威力、「敵複数に攻撃」は ○ 発を前衛の敵へ散らして当てる（本家どおり）
- **おはらい**は本家どおりタッチアクションをしたぶんだけ進む（放っておいても はらえない）
- ダメージの数字が出た瞬間に HP が減る。**多段攻撃は 1 発ずつ**数字とヒットストップを出す
- 前衛が全滅したら、倒れる演出が終わってからメンバーサークルが回る
- **対人戦**（オンライン。**ランダムマッチ**・**あいことば**でコードの手渡しなしにつながる。WebRTC、または同じブラウザの 2 画面）。持ち物（装備）は対人戦でも効く。回復などのアイテムはなし
- ひっさつわざのパワーチャージ（スキルチェック）・被弾・ひっさつわざ・回復・とりつきに光と衝撃波のエフェクト
- 編成画面の **流行りの型**：本家の通信対戦で流行った編成 6 つ（ブシニャン特化・赤鬼特化・ミツマタノヅチ特化・黒鬼ゾンビなど）をプリセットで入れられる。出典は [docs/PRESETS.md](docs/PRESETS.md)
- ひっさつわざは本家と同じく、タッチアクション（スキルチェック）を最後まで終えると発動。ためや出来の良し悪しで威力は変わらない
- メンバーサークル回しは指に遅れずについていき、離すと 60° ごとにぴたりと止まる
- メンバーサークルの回転は **妖怪の行動と同じ判定**：だれかの行動（こうげき・ようじゅつ・とりつく・ひっさつわざなど）のモーション中に回しても、そのあいだは並びを変えない。メンバーサークルは回した角度で光って待ち（「行動のモーションが終わったら回る」）、モーションが終わって次に行動する妖怪が決まる前に回る
- **ひっさつわざのモーション**を全員に：10 種の振り付け（跳び叩きつけ・連撃・回転突き・光線・天降らし・地鳴らし・竜巻・瞬影斬・祝福の光・しなり打ち）をひっさつわざの種類・属性・動きの癖で選び、回数・高さ・回転は 1 体ずつ変える
- 当たった瞬間のヒットストップ（ふつう 0.06 秒・クリティカル 0.26 秒・気絶 0.24 秒・ひっさつわざの決め 0.2 秒前後）
- ダメージの数字（ふつう・受けた・弱点・クリティカルで見た目がちがう）。クリティカルは金の大きな数字・放射線・ヒットストップ・専用の音。攻撃が続くと「○ HIT」と合計
- 本家の **装備 74 種**・**魂**・**たべもの／牛乳・ジュース／おふだ／漢方／みがわり人形**
- 本家の **パワーチャージ 4 種**・**おはらい 5 種**・右下の **アイテム**
- 本家の **性格 12 種**（短気・荒くれ・れいせい…動じない）と前半の **まじめさ**（超まじめ〜超ずぼら）。性格ボーナスも本家どおり
- 編成画面で 3D モデル・能力値（そうびこみ）・スキル・好物を確かめ、性格／そうび（装備・魂）／アイテムを選ぶ。選ぶ画面は種類でしぼりこみ・効果の大きい順などに並べかえができる。出陣前にまとめて確認

## 遊ぶ

- オンライン版：<https://s70rm3892.github.io/yokai-taisen/>（GitHub Pages）
- 1 ファイル版：[Releases](https://github.com/s70rm3892/yokai-taisen/releases) の `yokai-taisen.html` をダウンロードしてブラウザで開く

`main` に push すると GitHub Actions（`.github/workflows/release.yml`）がテスト → ビルド → Pages へ公開し、
`package.json` の version（例 1.0.0 → `v1.0.0`）の Release がまだ無ければ `yokai-taisen.html` を添付して作る。
版を上げるときは version を上げて main に入れる。同じものを `gh-pages` ブランチにも置く。
Pages を使うには、初回だけリポジトリの Settings → Pages で Source を「GitHub Actions」にするか、「Deploy from a branch」で `gh-pages` / `(root)` を選ぶ。

## 作り方

```sh
npm install
npm run build        # dist/index.html（これ 1 つで遊べる）
npm test             # 対戦ロジックを CPU どうしで数百戦させる＋全員の特性・装備を確かめる
node tests/smoke.mjs       # ブラウザで編成→対戦まで進めてスクリーンショット（dist/shots）
node tests/battle_ui.mjs   # アイテム・パワーチャージ 4 種・おはらい 5 種を実際に操作
node tests/pvp.mjs         # 対人戦を 2 ページで決着・再戦・切断まで（同じブラウザの 2 画面方式）
node tests/pvp_rtc.mjs     # 対人戦の WebRTC 接続（招待コード → 返事コード）
node tests/pvp_match.mjs   # マッチング（あいことば・やめる・ランダムマッチ）。手元に PeerJS のサーバーを立てて確かめる
node tests/presets.mjs     # 流行りの型：ルールを満たすか・持ち物が付くか・押して対戦できるか
node tests/pickers.mjs     # 性格・持ち物・アイテムの選ぶ画面（しぼりこみ・並べかえ・選んだものが入るか）
node tests/party_save.mjs  # パーティの保存：開きなおし・マイセット・書き出し／読みこみ・前の版の保存
node tests/battle_fx.mjs   # 陣のカットイン・とりつきのオーラとひっさつわざの封印・HP と多段ヒット・気絶時の向き
node tests/wheel_queue.mjs # 行動のモーション中にメンバーサークルを回す：その間は並びが変わらず、終わってから回る
python3 tools/gen_honke.py # 本家の妖怪のデータ（tools/honke_data/）から src/ext/honke_roster_data.js を作り直す
```

## 対人戦

編成画面の左「対人戦（人 vs 人）」から。いまの編成（性格・そうびこみ）で戦う。そうび（呪言の刀など）は対人戦でも効き、名札とログに出る。**回復などのアイテムはなし**（右下は「アイテムなし」）。

- **ランダムマッチ**：「相手をさがす」を押すだけ。いまさがしている人とつながる。だれもいなければ待つ（つながると音とタブの名前で知らせる）
- **あいことば**：友だちと同じ 4〜6 けたの番号を入れて「つなぐ」。先に押した方が部屋を作り、あとの人が入る。さそうリンク（`…#room=1234`）を開くだけでも同じ番号になる
- **コードで（サーバーなし）**：マッチングのサーバーにつながらないときの予備。招待コードを作って相手に送り、相手の返事コードを貼る（招待リンク `…#join=コード` も使える）
- **この端末で 2 画面**：同じブラウザで 2 つのタブを開き、同じ 4 けたの部屋番号で作る・入る

ランダムマッチとあいことばは、公開のシグナリングサーバー（PeerJS の無料サーバー `0.peerjs.com`）で「招待と返事」だけを中継してもらう。
サーバーでは名前（ID）ごとに 1 人しか待てないので、決まった名前（`yt<版>-rand`・`yt<版>-room-<番号>`）を先に取れた人が部屋を作る側、取れなかった人が入る側になる。
つながったらサーバーとの接続は閉じ、対戦は WebRTC のデータチャネルで直接やり取りする（接続の下準備に公開の STUN サーバーも使う）。版がちがう人とは当たらない。
おたがいの回線によっては（会社・学校のネットワークや一部のモバイル回線）つながらないことがある。

しくみ：部屋を作った側だけが対戦を進め、1 tick（50ms）ごとに「その tick の両者の入力」を送る。
対戦ロジックは同じ入力なら必ず同じ結果になるので、入った側も同じ入力を流して同じ対戦を再現する（5 秒ごとに状態をまるごと送って合わせ直す）。
入った側の画面は左右を入れ替えて見せるので、どちらも自分が手前になる。「あわせろ！」は押した瞬間に見えていた tick で判定する（通信の遅れで不利にならないように。1 秒以内まで）。

`dist/index.html#gallery=1`〜`#gallery=10` で全員の 3D モデルを 40 体ずつ並べて見られる。

## ファイル

- `src/template.html` … 画面の枠と CSS
- `src/game.js` … もとの公開版を読みやすく整形したもの（three.js を含む）。`/*@@include …@@*/` の場所に `src/ext/` を差し込む
- `src/ext/honke_items.js` … 本家の装備・アイテム（出典つき）
- `src/ext/traits.js` … 特性（本家のスキル）の説明文、好物、元祖軍／本家軍
- `src/ext/loadout.js` … 性格（本家の 12 種・まじめさ・性格ボーナス）と装備から対戦の能力値をまとめる
- `src/ext/engine_fx.js` … 特性・装備・アイテムの効果を対戦ロジックへ
- `src/ext/engine_minigames.js` … パワーチャージ 4 種・おはらい 5 種の判定と CPU
- `src/ext/models3d.js` … 3D モデルの部品と体つき・編成画面の回転プレビュー・3D モデルから撮るアイコン
- `src/ext/builder_ui.js` … 編成画面の確認・選択・出陣前の確認
- `src/ext/battle_ui.js` … 対戦画面のアイテムとタッチアクション（スキルチェックのエフェクトこみ）
- `src/ext/fx3d.js` … 3D の対戦画面のエフェクト（光の粒・衝撃波・光の柱・斬撃・チャージのオーラ・花びら）
- `src/ext/pvp.js` … 対人戦（通信・ロビー・同期）
- `src/ext/presets.js` … 流行りの型（プリセット）
- `src/ext/roster_plus.js` … 本家のスキル「ひとまかせ」「なめらかオイル」の効果
- `src/ext/party_save.js` … パーティの保存（本家の No・名前で保存・マイセット・書き出し／読みこみ・前の版の保存の引き継ぎ）
- `src/ext/motion3d.js` … ふだんの行動のモーション（こうげき 17 種・術の構え・とりつき・ガード・サボり・被弾・よける・気絶・登場・勝敗）
- `src/ext/fx_spells.js` … 術の陣と属性ごとの術のエフェクト、状態のしるし（結界・★・？・Z）
- `src/ext/ult_motion.js` … ひっさつわざの振り付け 10 種と、全員への割り当て
- `src/ext/honke_roster_data.js` … 本家の妖怪 398 体・スキルの説明・レア魂（`tools/gen_honke.py` が作る）
- `src/ext/honke_roster.js` … 本家のスキル 168 種・レア魂 27 種の効果と、本家の妖怪の登録
- `src/ext/honke_models.js` … 本家の妖怪の 3D モデル（手で決めた 173 体と、名前の言葉と種族から体つき・色を選ぶ残り）
- `src/ext/battle_view.js` … 見えている HP（演出と同時に減らす）・多段ヒット・陣のカットイン・とりつきのオーラ
- `tools/honke_data/` … 本家のデータ（攻略大百科・HRS・ゲームエイトから 2026-09 に取得）と取り出し用のスクリプト
- `tools/build.mjs` … 1 ファイルにまとめる（esbuild で圧縮）
- `tools/check_names.mjs` … 追加した名前が、圧縮済みの短い名前とぶつからないか調べる
